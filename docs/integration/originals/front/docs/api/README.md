# API 계약 문서

현재 저장소에는 실제 API 명세 원본이 없다. 제공된 PRD·기능명세서에 API 명세가 언급되어 있으나, 해당 원본을 확보하기 전에는 Endpoint나 DTO를 확정하지 않는다.

동일 Part의 FE/BE 담당자가 구현 전에 실제 명세를 기준으로 아래를 합의하고 작업 카드에 연결한다.

| 항목 | 기록할 내용 |
| --- | --- |
| Method / Endpoint | 실제 메서드·경로 |
| Request | path/query/body, 필수·선택, 형식·제약 |
| Response | 필드·타입·nullable·목록·집계 형식 |
| Status Code / Error | 정상·오류 상태 코드, 오류 코드·메시지·응답 구조 |
| 인증·권한 | 회원·게스트 접근, 이웃 인증 완료 지역, 유효 기관 인증·담당 지역 등 |
| 변경 이력 | 관련 기능 ID, 담당자, 변경 전후, commit SHA, 적용 순서·상대 담당자 확인 |

계약 합의 → 각 Part 구현·검증 → 실제 연동 확인 → develop 통합 순서로 진행한다. mock만 확인한 결과는 실제 연동 완료로 기록하지 않는다.
