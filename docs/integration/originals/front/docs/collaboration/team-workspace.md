# Discushion 팀 작업 현황

기준일: 2026-10-06. 운영 절차는 [Git/GitHub 협업 전략](Discushion_Git_GitHub_통합협업전략_2026-10-06.md)을 따른다. 이 파일은 초기 기록 양식이며 담당자와 기술 선택을 확정하지 않는다.

## 담당자와 작업 영역

| Part | 제품 영역 | FE 브랜치 | FE 담당자 | BE 브랜치 | BE 담당자 |
| --- | --- | --- | --- | --- | --- |
| A | 계정·프로필·지역·인증 | frontend-part-a | 미정 | backend-part-a | 미정 |
| B | 콘텐츠 탐색·게시물 관리 | frontend-part-b | 미정 | backend-part-b | 미정 |
| C | 주민 참여·공유·게스트 | frontend-part-c | 미정 | backend-part-c | 미정 |
| D | 개인 기록·기관 안건 업무 | frontend-part-d | 미정 | backend-part-d | 미정 |

- main 반영 담당자: 미정
- GitHub 쓰기 권한을 확인한 팀원: 미등록 (팀원 계정 확정 후 기록)
- 팀 채팅 및 develop 반영 공지 위치: 미정
- 현재 develop 반영자: 없음
- 반영 대상 SHA / 시작 시각 / 완료·보류 기록: 없음

A는 인증·지역 권한 계약, B는 게시물 원본·공통 상세, C는 참여·공유, D는 개인 기록·기관 채택을 맡는다. FE/BE의 동일 Part 문자는 동일 제품 영역이다. 공통 변경은 담당자·파일 범위를 먼저 합의하고 develop을 통해 전달한다.

## 세부 작업 기록

아직 기능 개발 작업은 등록하지 않았다. [작업 카드](task-card-template.md)를 복사해 세부 작업 하나씩 등록한다.

| Part | 담당자 | 세부 작업 | 상태 | 기능명세 ID | 실제 API 계약 링크 | FE/BE 연동 | 완료 여부 | 검증 명령·SHA·결과·확인자 | 사람의 검토 결과 | Part SHA / develop 반영 SHA | 의존성·특이사항 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

상태: `대기 → 진행 중 → 검증 중 → 완료 → develop 반영 완료`. 진행할 수 없으면 `보류`와 이유를 기록한다. 실제 연동을 확인하지 못하면 `연동 미확인`으로 기록한다.

## 실행·검증 환경 등록

| 영역 | 실행 위치 | 실제 실행 명령 | 테스트 명령 | 빌드 명령 | 상태 |
| --- | --- | --- | --- | --- | --- |
| Frontend | frontend/ | 미정 | 미정 | 미정 | 기술 스택 확정·초기화 전 |
| Backend | backend/ | 미정 | 미정 | 미정 | 기술 스택 확정·초기화 전 |
| FE/BE 연동 | 미정 | 미정 | 합의된 시나리오·테스트 계정·인증 지역 등록 필요 | 해당 없음 | API 원본 및 실행 환경 미준비 |

현재는 문서·폴더 골격만 있어 기능 테스트와 빌드는 실행할 수 없다. 기술 스택 초기화 후 실제 설정과 일치하는 명령을 등록한다. 실행하지 않은 검증을 통과로 기록하지 않는다. 실제 비밀번호·토큰·증빙 자료는 이 문서에 기록하지 않는다.

## 개발 시작 전 남은 합의

- FE/BE 기술 스택과 초기화 담당자
- Part별 담당자, main 반영 담당자, 팀원 GitHub 쓰기 권한
- 팀 채팅과 develop 반영 순서 공지 위치
- 기존 API 명세 원본 확보 및 FE/BE 계약 합의
- 기준 문서의 확인 필요 항목 중 해당 세부 작업에 필요한 결정

## 이번 준비 작업 검증

- 제공된 기준·협업 문서 4개는 원본과 SHA-256 일치 확인
- 제품 기능 코드, 프레임워크 초기화, 실제 환경변수 값 없음
- 브랜치명으로 된 디렉터리 없음
- Git 변경의 공백 오류 및 문서 상대 링크 확인
- 통합 지침서 원본의 3·4행 끝 공백은 Markdown 줄바꿈 2칸으로, 원본 보존을 위해 유지한다. 새로 작성·수정한 협업 파일의 공백 검사는 통과했다.
- 기능 테스트·빌드·FE/BE 연동: 미실행 (애플리케이션 미초기화)
