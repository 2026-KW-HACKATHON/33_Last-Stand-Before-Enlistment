## 적용과 우선순위

이 기록과 PRD·기능명세서의 `2026-10-07 결정 반영`이 같은 주제의 변경 전 v10.1 문장·MVP 표·API 예시보다 우선한다. 기능 ID는 추적을 위해 유지한다. PRD·기능명세서는 2026-10-07 v10.2 파일명으로 갱신하고 저장소 참조를 함께 맞췄다. 변경 전 상세 내용은 이력 또는 후순위 참고이며 이번 MVP 구현·완료 조건으로 사용하지 않는다. 여기서 변경하지 않은 제품 정책은 기존 명세를 따른다.

## Privy와 로컬 회원

이메일 OTP로 최초 인증과 이후 로그인을 진행한다. 자체 이메일/비밀번호 검증, 비밀번호 설정·확인, 자체 가입 인증코드 발급·저장은 이번 MVP 목표에서 대체한다. 별도 일반 이메일 발송 서비스나 Supabase Auth를 추가 선택한 것으로 해석하지 않는다.

Privy 인증 성공과 Discushion 가입 완료는 구분한다. 최초 사용자는 필수 이용약관·개인정보 동의, 선택 마케팅 동의, 프로필·활동 지역을 완료해야 한다. 기존 회원과 가입 미완료 사용자의 이동을 구분하고 전체 과정에서 `returnTo`를 보존한다. 복귀만으로 게시·반응·평가·투표·북마크를 자동 실행하거나 게스트 의견을 회원 계정으로 이관하지 않는다.

Privy 식별자와 로컬 회원 연결, 이메일 중복 처리, 토큰 직접 검증/자체 세션 교환, 전달·보관·만료·갱신·오류·로그아웃의 이번 범위는 BE1·BE2·FE가 #74에서 합의한다. 기존 6자리·5분·60초·30분 5회·입력 5회 수치를 Privy 정책으로 확인 없이 강제하지 않는다. OTP 실패·취소·만료·재시도는 확인된 provider 동작과 FE 계약을 따른다. 비-MVP 계정 복구·이메일/비밀번호 변경·탈퇴는 범위를 확대하지 않는다.

## 시연 상태와 권한

증빙 제출·접수 화면/API와 심사·승인/반려·보완 메일·증빙 보관 운영은 이번 구현 및 인수 대상에서 제외한다. 기존 신청 진입점의 비노출 또는 대체 안내는 FE와 합의한다. 미구현 신청 화면으로 이동시키거나 성공한 접수처럼 표시하지 않는다.

별도 시연 계정의 완료 지역과 기관 유효 상태를 서버 데이터로 준비한다. 이웃 완료 지역 최대 3개, 대상 지역 참여 제한, 기관 담당 지역·현재 유효기간·파생 배지, 작성자 소유권은 유지한다. Privy 로그인·일반 가입·활동 지역 설정만으로 자격을 부여하지 않으며 기관 자격도 주민 참여의 이웃 자격을 대신하지 않는다.

#75에서 계정 역할/대상 지역/기관/유효기간·안전한 설정 방식·재실행/초기화 범위·실행 담당자와 보관 방법을 정한다. 일반 가입자가 사용할 공개 승인 API나 FE 역할 스위치로 자격을 생성하지 않는다. 실제 OTP 로그인과 권한 허용/제한을 검증한다. 시연 데이터 설정을 실제 증빙 심사 완료로 기록하지 않는다.

## 사진 업로드·삭제·24시간 정리

게시물 사진은 공개 열람한다. 업로드·교체·삭제에는 서버 인증 주체와 소유권 검증이 필요하다. 게시물 API의 공유 게스트 범위와 일반 탐색·지역 참여 정책은 기존 명세를 유지한다. 프로필 사진 정책은 이번 게시물 사진 정책에서 자동 도출하지 않는다.

저장소 직접 업로드를 권장하며 서명 업로드 권한·재개 가능한 전송 방식 등 세부 선택은 #74/#13에서 합의한다. 새로운 Endpoint·DTO·파일 상태 Enum·DB 컬럼을 이 기록에서 확정하지 않는다. 최종 연결하는 전체 사진의 형식·개수·합계·소유권·순서를 서버에서 검증한다. 실패 시 입력을 유지하고 미연결 파일은 임시 보관한다.

사진 제거·교체로 빠진 사진과 게시물 전체 삭제에 따른 사진은 저장 파일까지 삭제한다. DB 참조 제거와 Storage 삭제의 순서·실패 재시도/보상은 BE1·BE2가 합의한다. 다른 댓글·표·활동 기록 등의 물리 보존 정책을 사진 결정으로 함께 확정하지 않는다.

미완료 업로드의 보관 기한은 24시간이다. 시작 기준시각, 완료/미완료 판정, 정리 실행 간격, 업로드 진행 중·최종 연결 중 경합, 완료 파일 보호, 정리 실패 재시도/관측은 미정이다. 임시 파일의 공개 시점도 별도 합의한다. #13은 파일 상태/정리 로직, #30은 정리 실행환경을 담당한다. 이는 게시물 초안 임시저장 화면이나 API를 MVP에 추가한다는 뜻이 아니다.

## AI·배포 환경

AI는 공개 지역 안건 원문만 자연스러운 3문장 한 문단으로 요약한다. 실패·짧은 원문·quota/timeout 등에서 원문 우선 fallback을 유지한다. API 키는 Backend 외부 환경변수로 관리하고 FE에 노출하지 않는다. #20에서 실제 모델 ID·사용 가능 여부·호출과 출력 제한을 확인한다. 생성/저장·원문 수정 후 재생성·재시도·짧은 원문 판단 수치는 아직 합의하지 않았다.

사용량이 작은 해커톤 시연을 전제로 하되 무료 요금제·남은 용량·비용 0원·리소스 존재·배포 성공을 가정하지 않는다. #30에서 실제 Supabase/Privy/Gemini/Vercel 설정과 요금·키·도메인/DNS·CORS·실행 방식을 확인한다. 가비아 도메인 보유와 인증 메일의 자체 도메인 발신은 별개의 설정이다.
