# Discushion — PRD

### 2026-10-07 사진 실행 방향 추가 결정

사용자가 사진 처리 1~4번 추천안을 채택했다. 이 절은 같은 주제의 앞선 합의 대기 표현보다 우선하며 다른 제품 권한·사진 한도는 유지한다.

- 사진은 소유자에게 연결하고 업로드 지역에 묶지 않는다. 가입 완료 회원의 업로드·파일 소유권을 확인하며, 최종 게시물 생성/수정/삭제 때 대상 지역 자격·게시물 소유권·유형/상태 제약을 다시 검사한다.
- BE가 실제 파일의 형식/크기를 검증한 최초 완료시각부터 24시간 동안 게시물 미연결이면 정리 대상이다. 완료시각이 없는 전송 중단 파일은 최초 업로드 예약부터 24시간을 적용한다. 재호출/권한 재발급으로 기한을 연장하지 않는다. 1시간마다 조사하며 취소·검사 실패는 즉시 삭제 예약한다. 연결 완료·LEGACY 파일과 실제 활성 참조는 자동 정리에서 보호한다.
- 발급 권한의 마지막 만료를 추적하고 취소/정리 후 늦은 업로드·재생성도 정리한다. 저장 경로는 재사용하지 않는다. token/서명 URL 원문은 저장·로그에 남기지 않는다.
- 파일 연결과 게시물 참조·상태 갱신은 공통 파일 행 잠금과 같은 DB 트랜잭션으로 처리한다. 사진 제거/교체/게시물 삭제는 참조 처리와 삭제 예약을 함께 기록하고 커밋 후 저장 파일 삭제를 시도한다. 실패는 영속 기록으로 재시도한다.
- 사용자 요청의 성공은 관계 제거/취소와 삭제 예약의 확정이며 실제 파일 삭제 완료와 구분한다. 늦은 전송의 재생성 방어까지 확인한 뒤 최종 삭제 완료로 처리한다. 삭제 예약만으로 저장 파일 삭제 요구를 충족한 것으로 표시하지 않는다.

세부 결정·DB 보완 요구는 [API 계약 검토표 §10.9](../api/Discushion_API_CONTRACT_검토표_2026-10-07.md#109-사용자-채택-사진-처리-14번-실행-방향-2026-10-07)를 따른다. BE1의 Schema/Migration 검토·반영과 API 경로/DTO·응답 코드·오류·bytes 환산·FE 데이터 계약 확인은 남아 있다. 미완료 전송 삭제 상태·마지막 발급 만료·worker 선점/복구 저장 구조와 진행 중 전송 종료/재확인 기준을 보완한 뒤 의존 코드를 구현한다. 이번 결정은 BE1/FE 승인·#74 완료·#13 구현·실제 Storage/FE 연동 완료를 뜻하지 않는다.

## 2026-10-07 결정 반영

사용자가 확정한 아래 변경이 같은 주제의 변경 전 v10.1 본문·예시·MVP 표보다 우선한다. 상세 근거와 남은 계약은 [MVP 결정 변경 기록](./Discushion_MVP_결정변경_2026-10-07.md)을 확인한다. 제품 범위·서비스 선택과 팀 계약 합의·실제 구현/연동 완료를 구분한다. 기능 ID는 유지하며 PRD·기능명세서의 현재 파일명과 참조는 v10.2로 갱신했다.

- **계정:** Privy 이메일 OTP로 인증·로그인한다. 최초 사용자는 필수/선택 동의·프로필·활동 지역을 완료해 로컬 회원으로 가입한다. 자체 비밀번호 설정·확인·로그인과 자체 가입 코드 발급은 대체한다. OTP 세부 제한과 토큰/회원 연결 계약은 #74에서 합의한다. `returnTo`를 전체 과정에서 보존하고 복귀만으로 참여·북마크를 자동 실행하지 않는다.
- **이웃 자격:** 증빙 선택·첨부·신청 제출·접수·실제 인증 처리는 이번 MVP에서 제외한다. 별도 시연용 계정의 완료 지역을 서버에 준비하고 상태 조회·최대 3지역·해당 지역 참여 자격은 유지한다. 일반 가입·Privy 로그인·활동 지역 설정·기관 자격만으로 이웃 자격을 부여하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#11을 따른다.
- **기관 자격:** 기관 증빙 입력·첨부·자료 제출·접수·실제 심사는 이번 MVP에서 제외한다. 별도 시연용 계정의 기관 정본·담당 지역·유효기간/완료 상태를 준비하고 현재 유효 상태 기반 역할·배지·업무 권한은 유지한다. 기관 자격이 주민 참여의 이웃 자격을 대신하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#12를 따른다.
- **사진:** 게시물 사진은 Supabase Storage에 저장하며 회원·게스트·사진 URL을 아는 앱 외부 사람 모두 열람할 수 있다. JPG/PNG·최대 10장·게시물 합계 10MB를 유지한다. 사진 제거·교체 및 게시물 전체 삭제 시 해당 저장 파일을 지운다. 미완료 업로드는 임시 보관 후 24시간이 지나면 정리한다. 2026-10-07 추가 결정으로 미완료 임시 사진도 업로드 직후 URL을 아는 사람에게 공개 열람을 허용한다. 아래 같은 주제의 공개 시점 합의 대기 표현보다 이 결정을 우선한다. 업로드 권한·최종 연결·bytes 환산·삭제 보상·24시간 기준시각/정리 간격/경합은 #74/#13/#30에서 합의한다. 이는 게시물 임시저장 기능을 추가한다는 뜻이 아니다.

## 확정 정책 보완 (2026-10-04)

이 절은 본 문서의 기존 문장과 미정 질문 중 아래 항목과 충돌하는 내용을 대체한다.

- 게시물의 `공감해요`, `필요해요`, `궁금해요`는 각각 반응 유형이며, 일반 명칭은 `반응`이다. 게시물 `반응 수`는 공감해요 수 + 필요해요 수 + 궁금해요 수이다. `공감해요` 버튼 이름은 유지한다.
- 해당 게시물 지역의 이웃 인증을 완료한 로그인 회원은 댓글과 답글에 `좋아요`와 `싫어요`를 남길 수 있다. 공유 링크 게스트는 댓글·답글 작성만 가능하고 좋아요·싫어요 평가는 할 수 없다. 두 평가는 상호배타적이고, 반대 버튼을 누르면 기존 평가를 바꾸며 현재 선택 버튼을 다시 누르면 취소한다. 댓글 정렬은 `좋아요순`(부모 댓글 좋아요 수 내림차순, 동률이면 최신 작성 우선)과 `최신순`이며 답글은 부모 댓글 아래에 두며 답글의 좋아요 수를 부모 댓글 정렬 기준에 합산하지 않는다.
- 회원이 댓글 또는 답글에 좋아요나 싫어요를 남기면 해당 게시물은 `참여한 게시물`에 포함한다. 게시물 반응, 댓글·답글 작성, 댓글·답글 평가, 투표 참여도 같은 목록에 기록한다.
- 게시물 유형은 `지역 안건`, `지역 활동 정보`, `투표`로 통일한다. 투표는 독립 게시물이다. 게시 완료 후 게시한 게시물의 상세로 이동한다.
- 게스트는 공유받은 특정 게시물 상세 컨텍스트 안에서만 이용하며 일반 메인·통합 게시판·전체 지도 탐색은 제공하지 않는다. `게스트` 이름으로 댓글과 답글을 작성할 수 있고 답글은 원 부모 댓글 아래 1단계만 저장한다. 기존 답글에 답하면 동일 부모 아래에 저장하고 대상 사용자명을 표시한다.
- 기관 인증 사용자는 익명 게시물을 작성할 수 없다. 기관 담당자는 전체 안건을 열람하고 게시물 반응 수 내림차순으로 확인할 수 있으며, 자신에게 인증된 담당 지역의 지역 안건만 채택해 기관 ↔ 지역 안건 관계/기록을 생성한다. 채택은 게시물 상태 변경이 아니다. 반응 수는 위 합계 정의를 따른다.
- 지역 참여 기능(게시, 댓글·답글, 게시물 반응, 댓글·답글 평가, 투표)은 해당 지역 이웃 인증을 완료한 회원만 사용할 수 있다. 게스트 공유 링크 댓글·답글은 예외다. 다른 지역은 열람 전용이다.
- 탐색 지역을 바꾸면 현재 탐색 지역만 임시 변경하며 기본 활동 지역은 유지한다. 관심 지역 개수 제한 없음은 비-MVP 최종 정책으로 유지한다.
- 투표는 선택지를 고른 뒤 `투표 제출` 버튼을 눌러 제출한다. 기존 선택이 있는 상태에서 다른 선택을 제출하면 `선택을 변경하시겠습니까?` 확인을 거친다. 확인 시 기존 표를 대체하고 취소 시 기존 표를 유지한다.
- 이용약관 동의와 개인정보 수집·이용 동의는 필수이고 소식·이벤트/마케팅 수신 동의는 선택이다. 필수 동의가 없으면 회원가입을 완료할 수 없다. 이웃 인증은 해당 지역 거주민의 지역 참여 자격 확인 절차다. 증빙 선택·첨부·신청 제출·접수·실제 인증 처리는 이번 MVP에서 제외한다. 별도 시연용 계정의 완료 지역을 서버에 준비하고 상태 조회·최대 3지역·해당 지역 참여 자격은 유지한다. 일반 가입·Privy 로그인·활동 지역 설정·기관 자격만으로 이웃 자격을 부여하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#11을 따른다. 최종 제품의 운영자 정성 평가·제출 후 1주일 이내 응답·승인 완료 조건은 비-MVP 심사 정책으로 유지한다. 한 사용자는 최대 3개 지역까지 이웃 인증을 완료할 수 있다. 구체적으로 인정할 거주 증빙 종류와 운영 데이터 구조 세부는 후순위로 두되 MVP 상태·완료 지역 관계 저장은 포함한다.

## 한 줄 정의

지역 주민에게 지역 문제 참여와 해결의 기회를 제공하여 주민이 지역 변화에서의 주도권을 가지게 한다.

## 제품 목표

주민이 지역 문제에 대한 정보가 없거나 참여할 시간이 없어서 지역 문제에 잘 참여하지 않는다. 이러한 상황에서 주민들이 쉽게 참여하도록 만든다.

## 추진 배경

주민의 참여가 충분히 이루어지지 않으면 지역의 다양한 의견이 정책과 지역 변화 과정에 반영되지 못하고, 일부 의견에 편중되거나 추후 주민 간·행정과 주민 간 갈등으로 이어질 수 있다.

## 사용자 문제

사용자, 즉 주민은 참여 창구에 대한 정보를 별로 가지고 있지 않으며, 참여할 시간 또한 부족하다. 결국 주민의 다양한 의견이 정책과 지역 변화 과정에 반영되지 못하고, 일부 의견에 편중되거나 추후 주민 간·행정과 주민 간 갈등으로 이어질 수 있다.

MVP 주요 사용자는 주민 회원, 공유 링크 게스트, 기관 인증 사용자(민원담당자)다. 기존 회원 역할은 지역 문제 참여자와 기관 인증 사용자로 유지하고 거주자·학생·직장인·상인은 복수 선택 가능한 프로필 속성으로 유지한다. Privy 이메일 OTP로 인증·로그인한다. 최초 사용자는 필수/선택 동의·프로필·활동 지역을 완료해 로컬 회원으로 가입한다. 자체 비밀번호 설정·확인·로그인과 자체 가입 코드 발급은 대체한다. OTP 세부 제한과 토큰/회원 연결 계약은 #74에서 합의한다. `returnTo`를 전체 과정에서 보존하고 복귀만으로 참여·북마크를 자동 실행하지 않는다. 이용약관·개인정보 수집·이용은 필수, 마케팅/소식 수신은 선택이며 필수 동의 없이 완료할 수 없다. 인증 재발송·불일치·만료·발송 실패 처리도 MVP다. 로그인 실패는 `로그인에 실패했습니다`로 안내하고 이메일 존재 여부 등 구체 원인을 구분하지 않는다.

게스트는 공유 링크로 받은 특정 게시물 상세에서만 공개 본문·사진·댓글/답글·반응 수·투표 결과를 열람하고 `게스트` 이름으로 댓글/답글을 작성한다. 일반 메인·통합 게시판·전체 지도는 탐색하지 않는다. 게시물 반응·댓글 평가·투표·북마크 시도 시 `로그인이 필요한 기능입니다.` 안내 후 로그인으로 이동한다. 로그인/가입 과정에서 returnTo를 보존하고 완료 후 원 게시물로 복귀하며 기존 동작을 자동 실행하지 않는다. 일반 진입은 메인으로 이동한다. 게스트의 전화번호 인증·문자 알림과 가입 후 게스트 댓글 자동 이관은 제공하지 않는다.

지역 게시·댓글/답글·반응·댓글 평가·투표는 해당 지역 이웃 인증 완료 회원만 가능하고 공유 링크 게스트 댓글/답글만 예외다. 활동 지역 설정·기관 인증은 이웃 인증을 대체하지 않는다. 다른 지역은 열람 전용이다.

[핵심 기능과 화면]

MVP 시작 화면은 브랜드·슬로건·로그인·회원가입 진입을 제공하고 이미 로그인한 사용자는 시작 화면 → 메인 화면 순서로 이동한다. 메인은 현재 지역 콘텐츠와 통합 게시판·이슈 지도·게시물/투표 상세 진입을 제공한다. 하단의 메인·지도·글쓰기·마이는 포함 기능에 연결하고 알림은 MVP 필수 메뉴에서 제외한다. 현재 탐색 지역의 콘텐츠가 없으면 해당 섹션과 게시판 CTA를 유지하며 `아직 등록된 게시물이 없습니다.`를 표시한다.

통합 게시판은 지역 안건·지역 활동 정보·투표 세 유형을 같은 공개 목록에서 조회하고 지역·유형·주제를 필터링한다. 지역 조건 아래 유형을 먼저 선택하고 해당 유형의 주제를 선택한다. ‘전체’는 조회 필터이지 저장값이 아니다. 주제는 교통·주거·안전·복지·생활정보·환경·기타다. 목록은 공개 정보·반응 수·댓글 정보를 표시하고 신규 게시물도 동일 원본 목록에 반영한다. 기본 활동 지역과 임시 탐색 지역을 구분한다.

AI 안건 요약은 MVP다. 공개 지역 안건 원문의 핵심을 자연스러운 3문장 한 문단으로 제공하고 원문에 없는 사실을 추가하지 않는다. 생성 상태를 표시하고 실패하거나 원문이 짧으면 원문을 우선 제공한다. 요약과 원 게시물을 연결하고 원문 열람 경로를 제공한다. 게스트 요약 열람은 공유받은 상세에 한정한다. AI 추천·개인 맞춤 추천·추천 새로고침과 관심 지역/키워드는 비-MVP이며 요약에 필요하지 않다.

[통합 게시물 작성·열람]

세 게시물 유형 모두 MVP 작성·조회·수정·삭제를 제공하며 공통 지역·주제·제목·본문·선택적 사진을 같은 게시물 시스템에 저장한다. 게시 완료 후 해당 상세로 이동하고 공개 목록·내가 만든 게시물에서 같은 원본을 조회한다. 지역 안건에는 별도 진행 상태가 없고 활동 입력을 표시하지 않는다. 임시 저장·참고 자료 링크·익명 작성은 이번 MVP에서 제외한다.

지역 활동 정보는 출처·일정·장소·활동 상태를 필수 입력하고 외부 참여 링크는 선택 입력한다. 상태는 기본값 없이 예정·진행·종료·취소 중 하나를 필수 선택한다. 작성자가 네 상태 사이에서 자유롭게 직접 변경하며 시스템은 자동 변경하지 않는다. 종료/취소면 외부 참여 경로를 비활성화하고 예정/진행으로 되돌리면 재활성화할 수 있다. 문의 정보는 별도 이메일 입력 없이 작성자의 현재 등록 로그인 이메일을 사용하며 회원과 공유 링크 게스트에게 표시한다. 문의 정보가 없으면 `주최자 문의 정보를 확인할 수 없습니다.`를 표시하고 외부 링크의 유무/오류와 분리한다. 내부 신청·결제는 제공하지 않는다. 계정 이메일 변경/탈퇴에 따른 문의 정보 갱신/제거 정책은 유지하되 그 계정 기능 구현은 비-MVP다.

투표는 독립 게시물이며 공통 항목·질문·선택지 2~10개·종료 일시·선택적 사진을 입력한다. 선택지 추가·수정·제거를 제공하되 최대 10개다. 진행 중/종료 상태와 실제 참여·결과를 제공한다. 진행 중 작성자는 제목·본문·사진·종료 일시를 수정할 수 있고 질문·선택지·지역·주제는 수정할 수 없다. 진행 중 투표는 작성자가 삭제할 수 있고 종료 후에는 수정·삭제할 수 없다. 최종 제품의 참고 자료 링크 수정과 종료 전 알림 입력/예약은 비-MVP다. 알림 없이 투표를 작성·참여·종료할 수 있어야 한다.

사진은 세 유형 모두 선택 사항이다. JPG·PNG 최대 10장, 게시물 전체 합산 최대 10MB이며 개별 파일당 10MB 기준이 아니다. 카메라/갤러리에서 첨부·미리보기·교체·제거하고 이동·선택 취소 시 공통 및 유형별 입력과 기존 사진을 유지한다. 사진이 없으면 목록·상세의 이미지 영역을 생략하고 기본/대체 이미지를 넣지 않는다. AI 이미지 생성은 비-MVP다.

[참여와 개인 활동]

공통 상세는 유형·주제·지역·제목·본문·작성자·사진·반응·댓글/답글·공유·북마크를 제공하며 해당 유형의 투표/활동 정보 및 현재 기관 채택 정보를 표시한다. 신고·참고 자료 링크와 익명 작성은 비-MVP다. 공감해요·필요해요·궁금해요는 각각 독립 등록·취소하며 세 개 모두 복수 선택할 수 있다. 반응 수는 세 반응 수의 합이고 투표 득표·댓글 수와 별도로 집계한다.

댓글/답글 작성·조회와 좋아요/싫어요 평가, 좋아요순/최신순 정렬은 MVP다. 평가는 상호배타적이며 반대 버튼은 전환, 같은 버튼은 취소한다. 좋아요순은 부모 댓글 좋아요 수 내림차순·동률 최신 작성 우선이고 최신순은 부모 작성 시각 내림차순이다. 답글은 원 부모 아래 1단계로 유지하며 기존 답글에 답해도 같은 부모 아래에 저장하고 대상 사용자명을 표시한다. 답글 좋아요 수를 부모 정렬에 합산하지 않는다. 회원·게스트 모두 동일한 사전 정의 문자열 포함 방식 금칙어 필터를 적용해 차단/수정 안내하거나 통과 시 즉시 게시한다. 실제 단어 목록은 임의로 결정하지 않고 AI 유해 문맥 판단·운영자 관리 UI는 제외한다.

투표는 선택 후 `투표 제출`로 저장한다. 종료 전 다른 선택을 제출하면 `선택을 변경하시겠습니까?` 확인 후 기존 표를 대체하고 취소하면 기존 표를 유지한다. 종료 후 신규 제출·변경을 제한한다. 선택지별 득표 수·득표율·전체 참여자 수를 공개하고 본인의 실제 선택은 로그인 본인에게만 표시한다. 다른 참여자의 이름·개인별/익명 식별자별 선택은 공개하지 않는다.

북마크는 상세의 동일 버튼 하나에서 로그인 상태를 판정한다. 회원은 등록/해제하고 저장 성공 시 `저장되었습니다` 팝업 후 현재 상세를 유지한다. 게스트는 저장 없이 로그인으로 이동하고 로그인/가입 완료 후 원 상세에 복귀한 다음 다시 버튼을 눌러야 저장한다. 마이페이지 목록은 유형·주제로 조회하고 상세로 연결한다. 목록 카드에는 등록/해제 버튼을 추가하지 않는다. 게시물 삭제 시 북마크 관계를 자동 해제하고 목록에서 제거한다.

MVP 마이페이지 메뉴는 프로필·나의 활동·내가 만든 게시물·참여한 게시물·참여한 투표·북마크·프로필 수정·이웃 인증·기관 인증이다. 활동 지역 변경은 프로필에서 제공한다. 관심 지역/키워드·알림·기타 계정 설정·탈퇴는 MVP 필수 메뉴가 아니다. 닉네임은 중복 없이 최대 10자, 한 줄 소개는 최대 50자이며 저장된 프로필 변경은 비익명 게시물 작성자 정보에 반영한다.

[기관 인증과 회원 기능 접근]

증빙 선택·첨부·신청 제출·접수·실제 인증 처리는 이번 MVP에서 제외한다. 별도 시연용 계정의 완료 지역을 서버에 준비하고 상태 조회·최대 3지역·해당 지역 참여 자격은 유지한다. 일반 가입·Privy 로그인·활동 지역 설정·기관 자격만으로 이웃 자격을 부여하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#11을 따른다.

기관 증빙 입력·첨부·자료 제출·접수·실제 심사는 이번 MVP에서 제외한다. 별도 시연용 계정의 기관 정본·담당 지역·유효기간/완료 상태를 준비하고 현재 유효 상태 기반 역할·배지·업무 권한은 유지한다. 기관 자격이 주민 참여의 이웃 자격을 대신하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#12를 따른다.

접수/첨부만으로 인증을 완료하지 않는다. 실제 운영자 심사·승인/반려·보완 메일·백오피스는 비-MVP다. 해커톤 시연에서는 개발자가 이웃/기관 인증 완료 상태를 직접 설정할 수 있다. 완료 상태·완료 지역/담당 지역을 실제 권한 판정에 연결하고 파란 배지를 별도 플래그로 주지 않는다. 기관 역할·배지는 현재 유효한 기관 인증 완료 상태에서만 파생하며 이웃/이메일 인증으로 부여하지 않는다. 기관 인증의 1년 유효기간과 만료 시 권한/배지 제거 정책을 유지한다. 증빙 보관/삭제 운영은 후순위다. 기관은 실제 민원 업무 담당자만 의미하며 단순 소속 학생/직원은 대상이 아니다.

기관 인증 완료 사용자는 전체 공개 지역 안건과 주민 의견을 열람한다. 담당자 목록은 제목·지역·반응 수·댓글/의견 수·게시 시각과 지역 필터를 제공하고 반응 수 내림차순으로 정렬한다. 담당 지역은 열람 범위를 제한하지 않고 채택 권한만 제한한다. 담당 지역 공개 지역 안건을 채택해 기관↔안건 별도 관계에 채택 사용자·시각을 저장한다. 게시물 상태를 바꾸지 않으며 기관별 독립 채택/취소를 허용한다. 취소 이력은 내부 보존하고 현재 유효 관계만 기존 담당자 화면의 `채택한 게시물` 필터/구역과 일반 상세에 표시한다. 일반 공개 정보는 기관명·채택 시각이고 담당자 개인정보는 비공개다. 채택 알림 없이 저장·조회할 수 있으며 MVP는 채택까지로 검토 중/처리 중/완료·실제 해결·행정 시스템 연동은 제외한다.

[기능 간 데이터와 복귀]

게시물·첨부 사진·댓글/답글·반응·북마크·투표·기관 채택 관계와 개인 기록은 동일 원본을 참조한다. 기관 채택은 투표/활동 진행 상태와 분리한다. 상세에서 돌아갈 때 원래 지역·유형·주제 및 메인/지도/개인 목록 진입 맥락을 유지한다. 로그인/가입 중 returnTo를 유지하고 복귀만으로 반응·평가·투표·북마크를 자동 실행하지 않는다. 후순위 알림/추천 경로는 MVP 필수 이동 경로에서 제외한다.

[MVP 범위와 추가 정의]

이번 변경은 구현 우선순위만 조정한다. v9의 확정 제품 정책과 기존 ID는 유지하고 v9 파일은 보존한다. `포함`은 MVP 구현·인수 대상, `제외`는 비-MVP/후순위, `일부 포함`은 항목 내부에 두 범위가 공존한다. `정책만 유지`는 MVP의 권한·표시·데이터 일관성을 지원하는 규칙이며 후순위 UI/API·운영 작업의 구현을 요구하지 않는다.

주요 사용자 컨텍스트는 주민 회원, 공유 링크 게스트, 기관 인증 사용자(민원담당자)다. 기존 계정 역할 ID는 두 회원 역할을 유지하며 게스트를 새 계정 역할로 추가하지 않는다.

증빙 선택·첨부·신청 제출·접수·실제 인증 처리는 이번 MVP에서 제외한다. 별도 시연용 계정의 완료 지역을 서버에 준비하고 상태 조회·최대 3지역·해당 지역 참여 자격은 유지한다. 일반 가입·Privy 로그인·활동 지역 설정·기관 자격만으로 이웃 자격을 부여하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#11을 따른다.

기관 증빙 입력·첨부·자료 제출·접수·실제 심사는 이번 MVP에서 제외한다. 별도 시연용 계정의 기관 정본·담당 지역·유효기간/완료 상태를 준비하고 현재 유효 상태 기반 역할·배지·업무 권한은 유지한다. 기관 자격이 주민 참여의 이웃 자격을 대신하지 않는다. 계정 준비는 #75, 조회 계약은 #74/#12를 따른다.

지역 참여는 해당 지역 이웃 인증 완료 회원에게만 허용한다. 공유 링크 게스트 댓글/답글만 예외다. 기관 채택에는 현재 유효한 기관 인증과 해당 담당 지역이 필요하다. 기관 인증만으로 주민 지역 참여 자격을 대체하지 않는다.

MVP 게시물·댓글·반응·투표·북마크·개인 기록·기관 채택은 같은 원본과 관계를 참조한다. AI 요약은 추천·관심 정보 없이 동작하고, 댓글·반응·투표·채택은 알림 생성·예약·전달 없이 정상 저장·조회한다. 후순위 버튼·메뉴·입력·API·예약 상태를 MVP 필수로 요구하거나 연결되지 않는 진입점으로 제공하지 않는다.

[비-MVP / 후순위]

- AI 의제 추천·개인 맞춤 추천·추천 새로고침, 관심 지역·관심 키워드.
- 알림 목록·푸시·댓글/답글·게시물 반응·투표 종료·종료 전 예약·기관 채택/취소 알림, 수신 설정, 알림 예약 데이터·실행.
- 신고 진입·사유 입력·제출·접수부터 운영자 심사·경고 누적·계정 제재까지 신고 기능 전체.
- 비밀번호 찾기/재설정·계정 탈퇴·MVP에 필요하지 않은 계정 설정(등록 이메일/비밀번호 변경·다크 모드 등).
- AI 게시물 이미지 생성·프롬프트·재생성/수정.
- 지역 안건 임시 저장·참고 자료 링크·익명 작성. 활동 정보의 필수 출처 및 선택적 외부 참여 링크는 MVP에 포함하며 참고 자료 링크와 구분한다.
- 이웃/기관 인증의 실제 운영자 심사·승인/반려 UI·백오피스, 반려 사유 관리·보완 요청 이메일 실제 처리·증빙 보관/삭제 운영·운영 데이터 구조 세부.
- 외부 행정 시스템 연동, 기관 채택 이후 검토 중·처리 중·처리 완료 상태 체계와 실제 민원 해결.

[프로토타입 구현 범위]

이웃/기관 인증 신청·증빙 제출·접수 UI는 제외하고 시연용 완료 상태·지역/기관 자격 조회와 권한 판정을 MVP로 유지한다. 개발자 시연용 완료 상태를 허용하며 완료 상태 기반 권한을 구현한다. 실제 운영 심사는 제외한다. v9의 ‘실제 사용자 권한 부여 미구현’ 표현은 심사/승인 시스템 제외로 한정하고 상태 기반 권한 판정까지 제외하는 것으로 해석하지 않는다. v9에서 제공하던 제한된 신고 신청 UI도 이번 MVP에서는 제외한다. 기존 최종 제품 정책은 후순위로 보존한다.

[이메일 인증·비밀번호 정책]

Privy 이메일 OTP로 인증·로그인한다. 최초 사용자는 필수/선택 동의·프로필·활동 지역을 완료해 로컬 회원으로 가입한다. 자체 비밀번호 설정·확인·로그인과 자체 가입 코드 발급은 대체한다. OTP 세부 제한과 토큰/회원 연결 계약은 #74에서 합의한다. `returnTo`를 전체 과정에서 보존하고 복귀만으로 참여·북마크를 자동 실행하지 않는다. 기존 코드 길이·시간·재발송/시도 제한은 변경 전 정책이며 Privy에 확인 없이 강제하지 않는다.

새 비밀번호는 8~64자, 영문·숫자 필수, 일반 특수문자 허용·필수 아님, 공백 불가, 확인값 일치이며 안내는 `영문과 숫자를 포함한 8자 이상으로 입력해 주세요.`다. 가입에서는 이 규칙을 MVP로 적용하고 이메일 변경·비밀번호 변경·찾기/재설정은 공통 정책만 후순위로 유지한다.

[게시물 탐색·이슈 지도]

이슈 지도는 기본 활동 지역 중심이며 GPS/실시간 위치 추적·지도 표시용 위치 권한을 사용하지 않는다. 동 단위 지역 식별자를 게시물과 연결하고 동별 지역 안건·투표 중 반응 수 최고 1개를 대표로 선정한다. 활동 정보는 제외하고 동률이면 최신 작성 우선이다. 댓글 수·투표 표 수는 대표 반응에 합산하지 않는다. 대표가 있는 동은 제목·유형 말풍선을, 사진이 있으면 첨부 순서상 첫 사진 썸네일을 표시한다. 사진이 없으면 썸네일 영역을 생략한다. 후보 없는 동도 지도에 유지하고 선택 시 `등록된 게시물이 없습니다`를 표시한다. 확대/축소·상세 이동·로딩 오류/재시도를 제공한다. 반응 변경 후 재조회하면 최신 합계로 대표를 갱신한다. 메인 검색·현재 위치로 활동 지역 후보 찾기·인기글 누적 노출 등 확정 목록 밖의 보조 정책은 보존하되 MVP 필수 구현으로 확대하지 않는다.

[개인 참여 기록의 통합 조회]

내가 만든 게시물은 세 유형을 모두 포함하고 유형별 본인 원본 목록/상세로 연결한다. 추가 진행/종료 상태 필터는 제공하지 않되 투표 상태는 카드·상세에 표시한다. 참여한 게시물은 본인의 세 반응·댓글/답글·댓글/답글 좋아요/싫어요·투표 참여를 게시물별 하나의 카드로 모은다. 댓글/답글 작성은 `댓글 작성`, 댓글/답글 평가는 `댓글 좋아요·싫어요`로 묶고 현재 유효한 모든 행동을 표시한다. 취소된 행동만 갱신하고 다른 행동이 남으면 카드를 유지한다. 북마크만 한 게시물·다른 사용자가 내 글에 한 행동은 제외한다. 전체·지역 안건·지역 활동 정보·투표 유형 필터를 사용하고 빈 목록은 `아직 참여한 게시물이 없습니다` 및 게시판 CTA를 제공한다.

참여한 투표는 별도 페이지의 전체·진행 중·종료 구분과 본인 실제 선택·현재/최종 결과를 제공한다. 최다 득표를 본인 선택으로 추정하지 않는다. 투표가 삭제되거나 접근 불가해도 개인 참여 기록은 유지하되 상세에서 접근 불가를 안내하고 삭제 본문·선택지를 재노출하지 않는다. 종료 전 알림 정보는 비-MVP다.

나의 활동은 게시물 수와 다른 실제 행동 횟수다. 게시물 작성·북마크 등록·공감해요·필요해요·궁금해요 등록·댓글 작성·답글 작성·댓글 좋아요·댓글 싫어요·답글 좋아요·답글 싫어요·투표 참여를 각각 1회로 센다. 조회·수정/삭제·설정 변경·반응/평가 취소·좋아요↔싫어요 직접 전환·투표 선택 변경은 +0이다. 취소 후 동일 행동 재등록은 +1이고 북마크 해제 후 재등록도 +1이다. 투표 선택 변경은 기존 참여 1회를 유지한다. 알림 목록 구현 없이 원본 행동 기록에서 개인 목록·활동 횟수를 제공한다.

[최종 제품 정책 보존 — 비-MVP 및 정책만 유지]

아래 정책은 최종 제품용이며 이번 MVP의 화면·입력·API·운영 완료 조건이 아니다. 세부 규칙은 기능명세서의 기존 ID에 유지한다.

**AI 추천·관심 정보 — 비-MVP:** 지역 의제만 추천하며 활동 지역·관심 지역·관심 키워드만 입력으로 사용하고 행동 이력 등은 사용하지 않는다. 우선순위는 활동 지역 → 관심 지역 → 관심 키워드이며 가중치는 임의로 정하지 않는다. 새 추천은 현재 카드만 제외하고 후보가 없으면 현재 카드와 안내를 유지한다. 관심 지역은 개수 제한 없이 0개도 허용하고 탐색/추천에만 사용한다. 키워드는 일곱 주제 중 최대 4개·자유 입력 불가이며 추천에만 사용하고 저장 실패 시 기존 선택을 유지한다. 참여 권한이나 알림을 생성하지 않는다. ## MVP 기능 영역과 개발 작업 단위 정렬 (2026-10-06)

현재 저장소에는 PRD·기능명세서·API 명세만 있고 Frontend·Backend·shared의 실제 소스 폴더는 확인되지 않았다. 따라서 아래 `연결 개발 영역`은 존재하지 않는 폴더 경로를 선언하는 것이 아니라, 현재 API 명세에서 확인되는 Domain 경계와 기능명세서의 데이터 책임을 함께 나타낸다. 코드 구조가 생성되면 같은 Domain에 실제 경로를 연결해 갱신한다.

### 기능 영역 간 연결 원칙

- 게시물 원본은 목록·상세·지도·개인 기록·기관 담당자 목록이 함께 참조한다. 기관 채택은 게시물 상태가 아니라 기관과 지역 안건 사이의 별도 관계다.
- 이웃 인증 완료 지역은 게시물 작성과 주민 참여의 공통 전제이며, 기관 인증은 담당자 안건 열람·채택 권한만 추가한다. 두 인증은 서로 대체하지 않는다.
- 공유 링크 게스트 흐름은 동일한 공개 게시물 상세를 사용하되, 댓글/답글만 예외적으로 허용한다. 회원 전용 행동은 로그인 후 원 상세 복귀까지만 연결하고 자동 실행하지 않는다.
- AI 요약, 지도 대표 게시물, 개인 활동 기록은 게시물 사본을 만들지 않고 각각 게시물 원본과 참여 관계를 읽어 표시한다.

비-MVP 기능도 같은 Domain에 속할 수 있으나 이번 MVP 작업 단위에는 넣지 않는다. 예를 들어 AI 추천은 AI Domain의 후순위, 알림은 참여·채택 이벤트를 소비하는 후순위 Notification Domain이며, 신고·계정 설정·운영자 심사는 각각의 후순위 Domain으로 유지한다.

## 차별점

MVP는 지역 안건·지역 활동 정보·투표를 같은 게시물 시스템으로 제공하고 공유 링크·게스트 댓글로 첫 참여의 진입을 줄인다. 지역 기반 탐색·공개 원문 AI 요약·댓글/답글·반응·실제 투표·개인 기록으로 이해와 참여를 연결한다. 기관 담당자는 전체 공개 안건과 주민 의견을 읽고 담당 지역 안건을 채택하며 주민은 현재 채택 기관명·시각을 확인한다. 채택은 별도 관계이고 실제 민원 해결을 보장하지 않는다. AI 추천·알림은 후순위 차별점이며 MVP 효과 검증에 포함하지 않는다.

## 대상 사용자

지역 주민 모두가 사용할 수 있지만, 핵심 사용자로는 참여 창구에 대한 정보가 없거나 시간이 없어서 지역 문제에 잘 참여하지 못하는 사람들을 보고 있다.

## 사용자 시나리오 — MVP

김민수는 공유 링크에서 특정 게시물의 공개 본문·사진·댓글/답글·반응 수·투표 결과를 읽고 `게스트`로 댓글/답글을 남긴다. 북마크·반응·댓글 평가·투표를 시도하면 로그인 안내를 받는다. Privy 이메일 OTP로 로그인하고 신규 사용자는 필수/선택 동의 → 프로필 → 활동 지역 설정으로 로컬 가입을 완료한다. 완료 후 returnTo 게시물로 복귀하며 원 동작은 자동 실행하지 않는다.

김민수는 메인에서 현재 지역 콘텐츠를 확인하고 통합 게시판의 지역·유형·주제 필터 또는 이슈 지도 대표 게시물에서 상세로 이동한다. 지역 안건의 AI 3문장 요약과 원문을 확인한다. AI 추천이나 관심 정보 설정은 필요하지 않다.

김민수는 이웃 인증에서 지역을 선택하고 거주 증빙을 첨부해 신청을 제출한 뒤 접수 상태를 확인한다. 시연에서는 개발자가 완료 지역을 설정하고 그 지역의 참여 권한을 판정한다. 김민수는 인증된 지역에서 세 유형 게시물을 작성·수정·삭제하고 댓글·답글·평가·반응·투표에 참여한다. 투표 변경은 종료 전 확인 후 기존 표를 대체하고 종료 후에는 제한된다. 활동 상태는 작성자가 직접 변경한다.

김민수는 상세에서 북마크를 등록하고 마이페이지의 내가 만든 게시물·참여한 게시물·참여한 투표·북마크와 나의 활동 횟수를 확인한다. 참여 행동은 한 게시물 카드에 모으되 횟수는 실제 행동별로 집계한다. 알림 목록 없이 원본 기록으로 확인한다.

김지영은 별도로 준비한 시연용 기관 계정으로 Privy OTP 로그인한다. 서버의 유효 기관 자격·담당 지역에서 파란 배지·담당자 접근이 연결된다. 전체 공개 지역 안건과 주민 의견을 반응 수 내림차순/지역 필터로 열람하고 담당 지역 안건을 채택한다. 기관명·채택 시각만 공개하며 채택/취소 시 목록·상세를 갱신한다. 증빙 제출·접수·실제 심사·알림/행정 처리는 시연하지 않는다.

## 핵심 지표

기존에 지역 문제에 잘 참여하지 않던 사람들의 서비스 활동(게시물 게시, 댓글 남기기, 반응 남기기, 공유하기 등)의 빈도를 30% 증가시킨다.

## 리스크 및 검증 제한

채택된 게시물이 기관 인증 사용자(민원담당자)에게 전달되더라도 지역 고위 인사에게 이어질지는 불확실해 실제 해결에 도달하기 어려울 수 있다.

링크 공유와 게스트 참여로 초기 접근성을 높여도 이후의 지속적인 사용을 이끌 수 있을지는 미지수이다.

[와이어프레임 미리보기 제한과 미완료 검증]

현재 Manyfast 와이어프레임 미리보기에서 로그인 상태에 따른 북마크 조건 분기와 returnTo 복귀 경로 전달·복원을 실행하는 형식은 확인되지 않았다. 미리보기의 북마크 버튼은 저장 완료 팝업으로, 로그인 버튼은 메인 이동으로 고정되어 있다. 유저플로우의 ‘미리보기 제한/미지원’, ‘팝업 고정’, ‘메인 고정’ 표시는 이 도구 제한을 뜻한다.

서비스 요구사항은 유지한다. 동일한 북마크 버튼 클릭 후 회원은 저장·완료 팝업·현재 상세 유지를 수행하고, 게스트는 저장 없이 로그인으로 이동해야 한다. 로그인 성공 시 복귀 경로가 있으면 원래 게시물로, 없으면 기존 메인으로 이동해야 한다. 로그인 복귀 직후 자동 저장하지 않고 동일한 버튼을 다시 클릭했을 때 저장해야 한다. 미리보기의 고정 동작을 게스트 저장 허용이나 모든 로그인 후 메인 이동 정책으로 해석하지 않는다.

미리보기 팝업과 화면 이동만으로 실제 데이터 저장·권한 검증·로그인 상태 분기·게시물 복귀가 구현되거나 검증되었다고 판단하지 않는다. 이 동작은 실제 구현 시 검증할 미완료 항목으로 남긴다.

## 범위 대조 및 확인 필요 (2026-10-06)

- PRD와 기능명세서의 A~AA MVP 범위를 같은 기준으로 대조했다. 회원가입 전체·AI 요약·실제 투표·북마크·인증 신청/접수·기관 채택을 포함하고 추천·알림/투표 예약·신고·복구/탈퇴·운영자 백오피스를 제외한다.
- 지역 참여는 이웃 인증 완료 상태, 기관 채택은 현재 유효한 기관 인증과 담당 지역을 사용한다. 공유 링크 게스트 댓글/답글만 예외다.
- 북마크는 마이페이지와 활동 횟수 +1에 연결하고 참여한 게시물에는 북마크만 한 글을 넣지 않는다. 로그인/가입 복귀는 자동 저장/제출을 하지 않는다.
- 채택은 기관↔지역 안건 별도 관계다. MVP 기능은 추천·관심 정보·알림 예약·운영자 심사 UI에 의존하지 않는다.
- 확인 필요 — 기존 미정 세부만 유지: 실제 금칙어 문자열 목록, 이웃 인증에서 인정할 구체 거주 증빙 종류·반려 후 재신청 규칙, 인증/신고 운영 데이터 구조·증빙 보관/삭제 세부, 기관 보완 이메일 수신 주소·전화번호 별도 인증·회신 자료 연결, 경고 횟수별 제재 종류/기간/해제 기준. 임의 결정하지 않는다. 금칙어 실제 목록 외 대부분은 비-MVP 운영 세부이며 MVP 상태·지역 저장 및 권한 판정을 제외하는 근거가 아니다.
