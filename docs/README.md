# Discushion 문서

프로젝트의 개발 기준 문서와 협업 문서를 관리한다.

- `specs/`: PRD, 기능명세서, MVP Frontend/Backend 통합 지침서 등 제품 요구사항과 기능 기준 문서
- `collaboration/`: Git/GitHub 협업 전략, Part별 작업 분배, 개발 진행 현황, 팀 개발 규칙
- `api/`: Frontend/Backend가 합의한 API 계약 문서
- `architecture/`: ERD, Domain 구조, 시스템 구조, 데이터 흐름, 권한 구조 자료

## 기준 문서

- [PRD v10.1](specs/Discushion_PRD_2026-10-06_MVP반영_정리본_v10.1.md)
- [기능명세서 v10.1](specs/Discushion_기능명세서_2026-10-06_MVP반영_정리본_v10.1.md)
- [MVP 백엔드·프론트엔드 통합 지침서](specs/Discushion_MVP_백엔드_프론트엔드_통합_지침서.md)
- [Git/GitHub 협업 전략](collaboration/Discushion_Git_GitHub_통합협업전략_2026-10-06.md)

위 4개 파일은 제공받은 원본을 내용 수정 없이 복사했다. 통합 지침서와 협업 전략에 적힌 이전 파일명은 위 v10.1 파일로 대응하며 원문은 보존한다. 문서에 언급된 API 명세 원본은 이번에 제공되지 않았고 현재 저장소에도 없다.

제품 정책·MVP 범위는 PRD와 기능명세서의 확정 정책 보완, 범위 대조, 기능 ID별 명세를 우선한다. 통합 지침서의 권장안과 확인 필요 항목을 확정 정책으로 확대하지 않는다.
