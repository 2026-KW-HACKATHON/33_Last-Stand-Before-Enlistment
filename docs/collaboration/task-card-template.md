# 세부 작업 카드 양식

이 양식은 구현 지시가 아니다. Part 전체가 아닌 세부 작업 하나를 선택하고 아래 항목을 채운 뒤 요청한다.

## 작업 범위

- FE/BE 및 Part:
- 현재 브랜치:
- 담당자 / 상대 FE·BE 담당자:
- 세부 작업 / 상태:
- 관련 기능명세 ID / MVP 포함 범위:
- 수정 허용 파일 / 다른 Part 소유·수정 금지 범위:
- 완료 조건:
- 선행 작업 / 의존 계약 / 대기·보류 이유:

## API와 공통 변경

- 실제 API 명세 링크:
- Method / Endpoint / Request / Response:
- Status Code / Error Response / 인증·권한 조건:
- 공통 파일 변경 담당자·합의:
- 계약 변경 전후 / 적용 순서 / 상대 담당자 확인:

## 검증과 공유

- 실행 위치 / 명령 / 시각 / 대상 SHA / 결과 / 확인자:
- 기능 테스트 / build:
- 실제 FE/BE 연동 시나리오 / 결과:
- 사람이 검토한 diff / 확인자 / 결과:
- Part commit SHA / 원격 공유 결과:
- develop 반영자 / 시작 공지 / 반영 대상 SHA:
- develop 전체 테스트·build·연동 결과:
- develop 반영 SHA / push 확인 / 완료·보류 공지:

실행하지 않은 테스트나 실제 연동을 완료로 표시하지 않는다. 실제 secret·인증 증빙은 기록하지 않는다.
