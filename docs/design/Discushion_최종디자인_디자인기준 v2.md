# Discushion — 최종디자인 디자인 기준

- 추출일: 2026-10-06
- 대상: Figma `KW 해커톤 디자인` 파일의 **`최종디자인` 페이지**
- 페이지: [최종디자인 열기](https://www.figma.com/design/Wobmrjd8xSUNKQISplV5aR?node-id=1136-6698)
- 확인 범위: 396 × 852 모바일 화면 **157개**, 해당 페이지의 공통 UI 컴포넌트와 토글
- 단위: 크기·여백·간격·둥글기·그림자는 Figma px, 굵기는 font-weight
- 기준: 실제 노드 속성과 변수·스타일을 읽어 정리했다. 이미지 안에 포함된 글꼴·색상은 UI 토큰 집계에 포함하지 않았다.
- 반영 상태: 공통 UI·토글 텍스트 33개와 `Discushion/*` 텍스트 스타일을 Pretendard로 동기화했다. 공통 헤더·하단 메뉴의 정렬을 맞추고, 메인 헤더·전체 하단바·선택 칩을 공통 컴포넌트에 추가했다.

| 일부 단일 메뉴·버튼 배경 | #F0F0F0 | 로그인 비밀번호 찾기 등 개별 적용 |

- 선택된 칩은 **#0F7662 배경 + 흰색 글자**, 비선택 칩은 **#F3F4F6 배경 + #4B5563 글자**다.
- 색상 변수 모음은 `Discushion / Final UI`이며, 원시 색상 `primitive/*`를 의미 색상 `color/*`가 참조한다.
- #0F766E와 #0F7662를 같은 HEX로 합쳐 기록하지 않는다. 현재 디자인에는 두 값이 함께 사용된다.

- **A01 시작 슬로건만 Inter Bold 16 / 행간 AUTO**가 남아 있다. 이 항목은 공통 컴포넌트 밖의 개별 화면 텍스트다.

### 3.2 재사용 텍스트 스타일

`Discushion/*` 스타일의 폰트도 Pretendard로 동기화했다. 스타일 이름과 크기·행간은 유지했다.

| 스타일 | 크기 | 굵기 | 행간 |
|---|---:|---|---:|
| Discushion/heading | 24 | Bold · 700 | 34 |
| Discushion/section | 18 | Bold · 700 | 27 |
| Discushion/title | 17 | SemiBold · 600 | 26 |
| Discushion/body | 15 | Regular · 400 | 23 |
| Discushion/label | 15 | Medium · 500 | 23 |
| Discushion/button | 15 | SemiBold · 600 | 23 |
| Discushion/caption | 12 | Medium · 500 | 18 |
| Discushion/nav | 11 | Medium · 500 | 17 |

- `heading` 24는 등록된 스타일 값이다. 실제 모바일 헤더는 **18 / 27**이다.
- 공통 토글 ON/OFF 원본 라벨은 Pretendard Regular **13 / 20**, L08 실제 인스턴스 라벨은 **15 / 23**이다.

### 4.4 Shadow

| 토큰 | CSS 대응값 | Figma 대응 |
|---|---|---|
| `shadow/card` | `0px 3px 10px 0px rgba(15, 23, 41, 0.04)` | `Discushion/Card` 효과 스타일 |
| `shadow/bottomNavigation` | `0px -2px 8px 0px rgba(15, 23, 41, 0.05)` | 실제 하단바 효과 |

- 색상은 Figma RGB를 8비트로 반올림한 값이다. 원본 정밀값은 14번에 기록했다.
- **기존 Figma 변수**와 **문서 기준명**을 구분한다. 문서 기준명은 이 문서에서 재사용할 값의 이름이며, 새 Figma 변수나 코드 파일을 생성했다는 의미는 아니다.
- 컴포넌트마다 해당 역할의 토큰을 사용한다. 모든 요소에 같은 패딩·Radius·Shadow를 일괄 적용하지 않는다.

| EmptyState | 빈 상태 화면은 존재, 독립된 공통 원본 미확인 | 공통 원본 제작·규격 확정 필요 | 제목·설명·선택적 행동 버튼을 재사용할 공통 구조 필요 |

- **제작 완료**는 공통 컴포넌트 원본이 있다는 뜻이다. 모든 기존 화면이 해당 원본의 인스턴스로 연결됐거나, 모든 상태 Variant가 완성됐다는 의미는 아니다.
- 현재 기본 Button은 세 가지 역할의 개별 컴포넌트다. Hover·Pressed·Loading 등 별도 상태의 완성 여부는 이 목록에서 완료로 처리하지 않는다.
- Modal과 BottomSheet는 서로 다른 표시 방식이다. 이름만 바꿔 같은 컴포넌트로 간주하지 않는다.

### 5.3 재사용·변형 기준

- **Button:** 동일한 역할은 같은 원본을 사용하고 문구만 교체한다. 배치에 따라 너비를 바꾸되 높이 52와 글자 기준을 유지한다. 기본 너비 364, 2열 178, 3열 116을 참조한다.
- **Input / TextArea:** Input은 짧은 입력, TextArea는 본문 입력에 사용한다. 기본 라벨·값 글꼴과 패딩을 유지하고 여러 줄 내용에 맞춰 높이를 조절한다.
- **Header:** 일반 화면은 Back 또는 Action, B01 형태는 Main을 사용한다. 뒤로가기·제목·톱니바퀴의 정렬 컨테이너를 유지한다.
- **BottomNavigation:** 전체 바의 5슬롯 정렬을 유지하고 현재 메뉴만 선택색으로 바꾼다. 글쓰기는 40 × 40 원형 버튼의 별도 구조를 사용한다.
- **PostCard:** 사진 유무에 맞는 원본을 선택한다. 제목·메타·반응 수를 바꾸고, 장문으로 높이가 늘어날 때 콘텐츠를 가리지 않도록 처리한다.
- **CommentItem:** 댓글 본문 구조를 재사용하고 부모·답글 관계는 목록 컨테이너가 담당한다. 한 단계 답글 들여쓰기는 22다.
- **Chip:** 선택·비선택 원본을 구분하고, 여러 줄 라벨은 높이 52 변형을 사용한다.
- **Notice:** 안내·주의·오류 역할에 맞춰 색상을 변경하고, 문구 줄 수에 따라 높이 42 / 60 / 78을 참조한다.
- **Toggle:** 실제 ON/OFF Variant를 사용한다. 화면별 라벨 크기 변형은 원본과 구분해 기록한다.

- 공통 Header/Back과 Header/Action에도 동일한 정렬용 컨테이너를 적용했다. Header/Action의 작은 `설정` 문구는 톱니바퀴로 교체했다.

### 12.2 B01 메인 브랜드 헤더

- 전체 크기: **396 × 58**, y=44.
- 패딩 좌 24 / 우 14, 요소 간격 12.
- 브랜드 영역: **270 × 58**, x=24.
- 설정 터치 영역: **32 × 58**, x=306. 아이콘 **32 × 32**.
- 알림 터치 영역: **32 × 58**, x=350. 아이콘 **32 × 32**.
- 브랜드 이미지 표시 크기 **35 × 32**, 서비스명 **20 Bold**, 부가 문구 **9 Regular**.
- 일반 헤더와 내부 패딩이 다르다. 메인 브랜드 헤더용 공통 컴포넌트 `Discushion/Header/Main`을 추가했다.

## 13. 하단 네비게이션·아이콘

### 13.1 하단바

- 전체 크기: **396 × 76**, x=0 / y=776.
- 배경 #FFFFFF, Radius 0, 1px #D5DDE3 Inside 테두리, 위쪽 그림자.
- Horizontal Auto Layout, 상하 패딩 8 / 좌우 패딩 16, 슬롯 간격 0.
- 슬롯: **메인 / 지도 / 글쓰기 / 알림 / 마이** 5개.
- 슬롯 기본 너비 **72.8**. 일반 항목 높이 **53**, 상하 패딩 4 / 좌우 패딩 2.
- 일반 아이콘 정렬 영역 **24 × 24**, 라벨 높이 **17**, 아이콘·라벨 간격 **4**.
- 라벨은 **11 / 17 Medium**, 중앙 정렬.
- 선택 메뉴: #0F766E, 비선택 메뉴: #667085.
- 글쓰기는 **40 × 40 원형 버튼**이며, 일반 라벨을 사용하지 않는 별도 배치다. 슬롯 프레임 높이 32 안에서 버튼이 위아래로 걸쳐 배치된다.
- 지도 아이콘의 실제 도형 bounds는 약 **24 × 22.77**이지만, 정렬 영역은 **24 × 24**다.
- 공통 NavItem을 높이 **53** / 상하 패딩 **4**로 맞췄고, `Discushion/BottomNavigation`에 전체 5슬롯 구조를 추가했다.

### 13.2 아이콘 크기 기준

| 종류 | 크기 | 설명 |
|---|---|---|
| 일반 하단 메뉴 | 24 × 24 | 도형보다 정렬 영역 기준 |
| 메인 설정·알림 | 32 × 32 | 터치 컨테이너는 높이 58 |
| 일반 헤더 설정 | 32 × 32 | 56 × 58 액션 영역 안 |
| 중앙 글쓰기 버튼 | 40 × 40 | 초록 원 + 흰색 플러스 |
| 뒤로가기 문자 영역 | 24 × 39 | 문자 크기 26, 행간 39 |
| 메인 브랜드 이미지 | 35 × 32 | 아이콘 체계와 별도 이미지 |

- 도형 bounds, 정렬용 컨테이너, 클릭·터치 컨테이너의 크기를 구분한다.
- 아이콘의 선 굵기는 에셋별로 다르다. 카드 테두리 1px을 아이콘 선 굵기로 일괄 적용하지 않는다.
